# كشته

نموذج مقترح من واقع للتصميم. افتح index.html أو شغّل python3 -m http.server 8080 داخل المجلد.

الموقع عربي ومتجاوب ويشمل دليل الخدمات، بطاقة رقمية، وبطاقة QR قابلة للطباعة. جميع الملفات محلية عدا خرائط قوقل وروابط التواصل.

النموذج لا يخزن ولا يرسل طلبات تلقائيًا: يجمع نصًا اختياريًا يراجعه المستخدم ثم يفتحه في واتساب أو ينسخه. لا يوجد تأكيد حجز أو دفع.

الصور من الحساب العام للمشروع، ومصادرها في asset-sources.json. يلزم اعتماد صاحب المشروع لحقوق الصور والبيانات والأسعار قبل تحويل النموذج إلى موقع رسمي. noindex يمنع الفهرسة العادية للنموذج ولا يمثل حماية وصول.
